# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Contact:** Please open a [GitHub Issue](https://github.com/98wrvgxrn9-ctrl/aomori-snow-tracker/issues) with the label `security`, or contact the maintainer directly.

**Response:** We will acknowledge your report within 48 hours and provide a fix as soon as possible.

**Scope:**
- Firebase Realtime Database rules
- Client-side XSS or injection vulnerabilities
- Exposed credentials or secrets

Please do **not** publicly disclose the vulnerability until a fix has been released.
