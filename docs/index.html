このマップの特徴

本マップは、行政公開情報を土台にしながら、市民側の体感を統計として重ねて見られるよう設計しています。

公式情報と市民体感の重ね合わせ

除排雪スケジュールと市民投稿を同じ地図上で比較できます。

直近7日間の傾向分析

市民投稿（FMS）は直近7日間分を集計し、毎日更新されます。古い投稿は自動的に入れ替わります。

行動に必要な生活情報

雪捨て場・市営バス運行状況など移動判断に直結する情報も扱います。

スタック危険度の可視化

「通れる/通れない」だけでなく、立ち往生リスクの偏りを工区単位で見られます。

本サービスについて

1. 目的と位置づけ

本サービス「青森除雪ウォッチ」は、青森市が公開している除排雪に関するオープンデータや、SNS上の市民体感を統計化し、地図上で傾向を可視化することを目的とした市民プロジェクトです。行政の評価・採点を目的とするものではありません。

青森市の除排雪事業を応援し、市民と行政の相互理解を促進するための補完的な情報ツールとして運営しています。行政の公式サービスの代替を意図するものではありません。

2. 行政機関の皆さまへ

  • 本サービスは、青森市をはじめとする行政機関の除排雪に関する取り組みに敬意を払い、その情報発信を補完する立場で運営しています。
  • 掲載内容に関するご要望・ご指摘がございましたら、速やかに対応いたします。データの取り扱いについてもご相談に応じます。
  • 行政機関との連携・協力の可能性についても、積極的に検討させていただきます。

3. 使い方

  • 除排雪の予定を確認する — 画面右側の「作業予定あり」「現場確認中」などのカードをタップすると、該当する工区・路線が地図上に色付きで表示されます。
  • スタックしやすい場所を確認する — 「市民報告」セクションに、直近7日間の通行リスク（スタック・走行注意など）が工区ごとにまとまっています。工区名をタップすると地図上で場所を確認できます。
  • 雪捨て場を探す — 地図上の緑色の丸印が雪捨て場です。タップすると名前・受入時間が表示されます。
  • バスの運休を確認する — 画面下部の「市営バス運行状況」から確認できます。「地図に表示」ボタンで運休区間を地図上に表示します。

4. 情報の正確性

  • 本サービスに掲載される情報は、行政が公開するオープンデータおよびSNS上の投稿を収集・加工したものであり、正確性・完全性・最新性を保証するものではありません。
  • 除排雪の作業予定・実施状況は、天候や現場の状況により予告なく変更される場合があります。最新の公式情報は青森市公式サイトをご確認ください。
  • 除排雪作業には優先順位があり、幹線道路から生活道路へと順次対応されています。作業の順序は限られた資源の中での最善の判断に基づいています。

5. 免責事項

  • 本サービスの利用により生じたいかなる損害についても、運営者は一切の責任を負いません。
  • 除排雪作業に関する判断は、必ず公式情報に基づいて行ってください。

6. 市民の皆さまへのお願い

  • 除排雪は限られた予算・人員・機材の中で行われています。本サービスの情報をもとに、現場の状況を理解した上でのご利用をお願いします。
  • SNS投稿を通じて情報提供いただく際は、具体的な場所や状況を添えていただけると、より有用な情報として活用できます。
  • 本サービスを利用した特定の個人・団体・行政機関への誹謗中傷はご遠慮ください。

7. SNS投稿の取り扱い

  • SNS上の公開投稿を収集・分析していますが、原文の公開は行いません。
  • 投稿内容は統計化・匿名化した上で、トピック構成や傾向のみを表示しています。
  • 個人が特定される情報は一切表示しません。

8. データソース・引用元

本サービスは以下の情報を引用・利用しています。各データの著作権・利用条件は提供元に帰属します。

  • 除排雪スケジュール: 青森市 — 雪についてのお知らせ（市が公開するオープンデータを引用）
  • 雪捨て場情報: 青森市公式サイト（公開情報を引用）
  • 市民レポート（FMS）: FixMyStreet Japan（公開投稿を統計化して引用。原文は各投稿ページをご参照ください）
  • 地図タイル: OpenStreetMap contributors

9. お問い合わせ

掲載内容に関するお問い合わせ・削除依頼・連携のご相談は、X（@aomori_snowatch）のDMまたはGitHubリポジトリのIssueまでご連絡ください。
